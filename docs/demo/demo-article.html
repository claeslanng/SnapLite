Getting started with Northwind Notes

Install the app, write your first note, and keep everything in sync across your devices.

Install the app

Northwind Notes runs on Windows, macOS and Linux. Download the installer for your system, or use your package manager if you prefer the terminal.

winget install Northwind.Notes
brew install --cask northwind-notes
sudo snap install northwind-notes
Tip: the first start takes a few seconds while your notebook is created. Later starts are instant.

Create your first note

Press Ctrl + N anywhere in the app. Notes are plain Markdown files, so they stay readable in any editor, forever.

Write

Markdown with live preview, tables and checklists.

Link

Type [[ to link notes together and build a map.

Find

Full-text search across every note in milliseconds.

Titles come from the first heading. Rename a note and every link to it is updated automatically.

Organise with tags

Add tags with a hash sign anywhere in a note: #project, #reading. The sidebar groups notes by tag, and you can nest tags with a slash: #work/meetings.

Saved searches combine tags and words, for example #work -#done deadline.

Sync across devices

Turn on sync in Settings › Sync and sign in. Notes are encrypted on your device before they are uploaded, so only you can read them.

Changes appear on your other devices within seconds. Working offline is fine: edits are merged when you reconnect.

Troubleshooting

Sync says "waiting for device"

Open the app on your other device once; it registers itself the first time it starts.

Where are my notes stored?

In Documents/Northwind by default. You can move the folder in Settings › Storage.

Can I import from other apps?

Yes: File › Import reads Markdown folders, Evernote exports and plain text.
